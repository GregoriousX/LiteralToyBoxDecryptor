# Disney Infinity 3.0

Wybierz **DI 3.0 (experimental)** w menu profilu gry. Program obsługuje dane Toy Boxów, screenshoty, nagłówki i pliki Toy Box Games, także nazwy z końcówkami literowymi.

**Deszyfrowanie PS3/Wii U i zgodność z grą nie zostały sprawdzone.** Obsługa konsol korzysta na razie z tej samej implementacji szyfrowania co Disney Infinity 1.0, na podstawie [LiteralCraba](https://github.com/GregoriousX/LiteralCrab).

Pliki PC zostały przetestowane. Eksport zachowuje oryginalne dane; program nie konwertuje światów, obiektów ani nowszych zapisów do Disney Infinity 1.0.
