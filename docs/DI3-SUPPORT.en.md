# Disney Infinity 3.0

Select **DI 3.0 (experimental)** in the game profile menu. The app handles Toy Box saves, screenshots, headers and related Toy Box Game files, including filenames with letter suffixes.

**PS3/Wii U decryption and game compatibility have not been tested.** Console support currently uses the same encryption implementation as Disney Infinity 1.0, based on [LiteralCrab](https://github.com/GregoriousX/LiteralCrab).

PC files have been tested. Exports preserve the original save data; the app does not convert worlds, objects or newer saves to Disney Infinity 1.0.
