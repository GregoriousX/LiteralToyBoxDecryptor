# LiteralToyBoxDecryptor

A simple Windows app for Disney Infinity 1.0 and 3.0 Toy Box saves.

- Dark interface, drag and drop, and batch processing.
- Open save files, folders, or ZIPs.
- Preview text and export readable files or unencrypted PC saves.
- Original saves stay untouched.

Download **LiteralToyBoxDecryptor.exe** from [Releases](https://github.com/GregoriousX/LiteralToyBoxDecryptor/releases). No installation or separate .NET download is needed. Requires 64-bit Windows.

Add your files, choose the game profile, then click **Decrypt batch**. For Disney Infinity 3.0, select **DI 3.0 (experimental)**.

**DI 3.0 is experimental. PS3/Wii U decryption and loading the exports in the game have not been tested.** PC sample files have been checked successfully.

Based on [LiteralCrab](https://github.com/GregoriousX/LiteralCrab). Licensed under [GPL-3.0](LICENSE).

To build from source, install the .NET 10 SDK and run `./build.ps1`.
